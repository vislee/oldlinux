> 一本写给大学一年级学生（或任何初级程序员）的操作系统教材。

## 一、这套教材特别在哪里

市面上操作系统教材分两类：一类讲理论（进程、调度、分页……），配少量伪代码；
另一类是内核大部头，直接把初学者拍晕。本教材走中间路线：

1. **理论够用就好**：每个概念先用生活比喻讲直觉，再给精确定义；
2. **源码都是真的**：所有"源码导读"指向本仓库里**真实存在**的代码
   （`linux-0.11/`、`linux-2.6.35/`、`nginx-0.1.0/`），你可以打开文件逐行对照；
3. **每章都能动手**：每章都有可在 macOS 或 Linux 上直接编译运行的实验程序和练习题。

本仓库的源码树就是教材的"实验器材"：

| 仓库目录 | 是什么 | 年代 | 教材用途 |
|---|---|---|---|
| `linux-0.00` / `linux-0.01` | Linux 诞生前夜的雏形与 0.01 版 | 1991 | 第 1 章历史，感受"内核可以很小" |
| `linux-0.11` | 第一个"五脏俱全"的稳定版内核 | 1991.12 | **本教材的主力源码**（第 3~10 章） |
| `linux-0.12` / `linux-0.98` / `linux-1.0` / `linux-1.2.0` | 成长期版本 | 1992~1995 | 对照阅读，看功能如何长出来 |
| `linux-2.4.0` / `linux-2.6.0` / `linux-2.6.12` / `linux-2.6.35` | 现代内核早期形态 | 2001~2010 | 对照现代做法（调度器、TCP/IP、VFS） |
| `nginx-0.1.0` | nginx 第一个公开版（已逐行中文注释） | 2004.10 | 用户态视角：如何"使用"内核（第 11~12 章） |
| `nginx-0.1.0/注释与理论说明.md` | TCP/IP 相关注释的理论地图 | — | 第 11、12 章的配套阅读 |
| `doc/Linux内核完全注释v5.0.pdf` | 赵炯著，对 linux-0.11 的逐行注释经典 | — | 每章"延伸阅读"的权威参考 |

## 二、读者需要会什么

- **必须**：C 语言基础——变量、函数、数组、指针初步、`struct`。不熟没关系，附录 B 有速查；
- **最好**：会用命令行（`cd`、`ls`、`gcc a.c && ./a.out`）；
- **不需要**：汇编（需要的指令第 2 章现场教）、操作系统先修课（本教材就是）。

## 四、每章的固定结构

1. **学习目标**——本章你要搞懂哪几件事；
2. **从一个问题开始**——生活化的场景引入；
3. **核心概念**——比喻 + 精确定义 + 图示；
4. **源码导读**——打开仓库里的真实文件，讲关键函数（如 `linux-0.11/kernel/fork.c` 的 `copy_process()`）；
5. **动手实验**——可编译运行的小程序；
6. **常见误区**——初学者最爱踩的坑；
7. **练习题**——附提示；
8. **延伸阅读**——《Linux内核完全注释》对应章节、现代内核对照。

## 五、环境准备

```bash
# macOS（安装 Xcode 命令行工具即可编译所有实验）
xcode-select --install

# Ubuntu/Debian Linux
sudo apt install build-essential

# 可选：跑 0.11 内核镜像需要模拟器（第 3 章实验用）
brew install qemu          # macOS
sudo apt install qemu-system-x86 bochs   # Linux
```

验证环境：

```bash
cd 本仓库
ls linux-0.11/kernel/fork.c     # 能看到文件即成功
gcc --version
```

> 仓库中的内核源码是 1991~2010 年的原始代码，**不要**用现代编译器直接编译它们
> （会有一堆兼容性报错）。读它们、在模拟器里跑现成的 `Image` 镜像即可；
> 我们自己写的实验程序（第 11~13 章）才是用现代 gcc/clang 编译的。
